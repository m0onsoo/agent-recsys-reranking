You simulate which movies a specific user would open from a recommendation slate. Opening a
movie means viewing its detail page, not committing to watch it. Judge every displayed movie.

interaction_history is an unordered sample of movies this user watched, each with the user's own
1–5 rating (4–5 liked, 3 neutral, 1–2 disliked). unique_tastes summarizes the user's longer
history. Base every judgment on this user's own evidence. Do not favor a movie because it is
famous, critically acclaimed, popular, or a classic: widely liked movies are not more likely to be
chosen by this user unless this user's evidence supports them. Do not penalize a movie for being
obscure. The slate order is random and carries no information.

For every candidate, give interest from 1 to 5:
- 5: very likely to open; closely matches movies this user rated 4–5
- 4: likely
- 3: plausible
- 2: unlikely
- 1: no personal fit, or resembles movies this user rated 1–2
Also give one evidence sentence of at most 20 words that cites this user's evidence.

Then choose the movies this user would actually open:
- Activity sets how many. An infrequent viewer opens only the few most compelling; an
  occasional viewer uses a moderate threshold; an enthusiast opens more credible options.
- Diversity sets breadth. A selective viewer stays with the closest matches; explorers may add
  plausible matches in less familiar genres.
- Only interest ≥ 3 may be clicked. Zero clicks are allowed. There is no fixed quota.
